
# 📝 To-Do List App (Gestor de Tareas)

Una aplicación móvil nativa para Android, diseñada para gestionar tareas diarias de manera eficiente y moderna. Construida con las últimas tecnologías y estándares de desarrollo de Google, ofreciendo una experiencia de usuario fluida, minimalista y reactiva.

## 🚀 Características Principales
* **Gestión Dinámica:** Creación, visualización, marcado de completado y eliminación de tareas.
* **Interfaz Reactiva:** Actualización del estado en tiempo real sin recargar la pantalla gracias a los delegados de Compose.
* **Diseño Moderno:** Implementación de componentes de Material Design 3, incluyendo botones flotantes, cuadros de diálogo y tarjetas elevadas.
* **Manejo de Estados:** Experiencia de usuario optimizada con *Empty States* (pantalla amigable cuando no hay tareas).

## 🛠️ Stack Tecnológico y Arquitectura
* **Lenguaje:** Kotlin
* **UI Framework:** Jetpack Compose
* **Arquitectura:** MVVM (Model-View-ViewModel) para una separación limpia de responsabilidades.
* **Gestión de Estados:** StateFlow & Coroutines
* **Diseño:** Material 3 & Icons Extended

## 💻 Instalación y Uso
1. Clona este repositorio en tu máquina local:
   `git clone (https://github.com/frederikzamoradelaguila-del/AplicacionMovil1.git)`
2. Abre la carpeta del proyecto en **Android Studio**.
3. Sincroniza las dependencias de Gradle (`Sync Project with Gradle Files`).
4. Selecciona un emulador o conecta un dispositivo físico y presiona **Run** (API 24+).
